# DevMeet AI Interviewer & Live Assessment Platform

DevMeet is an AI-powered technical interview and live pair-programming platform built with React, Node.js, Express, Socket.IO, and Google Gemini AI.

## Features
- **🤖 Aria AI Technical Interviewer**: Real-time voice & text interactive coding interviewer powered by Gemini 2.5 Flash.
- **⚡ Live Code Sandbox**: Monaco editor with real-time error line detection, line-jump diagnostics, and Judge0 execution support.
- **📊 Detailed AI Performance Reports**: Technical proficiency scoring, complexity analysis, and actionable feedback.
- **🔑 Google Single Sign-On**: Seamless SSO login for candidates and interviewers.

## Getting Started

### Backend Setup
```bash
cd backend
npm install
npm run dev
```

### Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
